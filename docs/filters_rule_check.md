# Проверка фильтров по правилу полноты (22.10.2026) — только разбор, на сайт ничего не записано

**Что проверял:** все 240 разделов каталога, где есть список товаров, во всех группах. Фильтры раздела — это план админки (`docs/admin_plan_filters.md`) вместе с тем, что уже стоит на витрине. На витрине фильтры сейчас настроены в 104 разделах: «Викрутки» 48, «Діелектричні» 38, «Біти» 18.

**Данные:** свежая выгрузка 3591 товара. Она совпадает с выгрузкой после записи 22.10 (g): с тех пор не изменился ни один товар. Плюс новый скан витрины — все 274 раздела, UA и /ru/. Паспорта WERA — PDF из `tools/batch/ds` (все страницы). Где состава в паспорте нет — страница товара на wera.de, блок «Werkzeuge in diesem Set».

**Правило из задачи:**
- **Параметр** (вид, профіль і розмір, розмір…, довжина…, діапазон / налаштування моменту, привід, розмір під ключ …): если отметить все значения фильтра, должны остаться все товары раздела.
- **Признак** («Особливості …», «… у складі»): значение может быть не у всех.
- Составные фильтры наборов («Тип біт у наборі», «Інструмент у ложементі») отнёс к признакам: набор либо содержит это, либо нет.

**Обозначения предложений:** (а) дописать по паспорту WERA — с цитатой; (б) убрать фильтр из раздела; (в) оставить — с объяснением.

  По смыслу это состав, как «… у складі». Решение здесь — или убрать фильтр, или считать его составом.

## 2. «Діапазон моменту»

**Сейчас.** 6 корзин: до 1, 1–5, 5–25, 25–100, 100–400, понад 400 Н·м. Товар получает каждую корзину, которую задевает его диапазон. Поэтому 0,3–1,2 Н·м стоит и в «до 1», и в «1–5»: при выборе «до 1 Н·м» покупатель видит ручку, которая работает до 1,2 Н·м.

**Как считал точные диапазоны:**
- Значение «Діапазон моменту» есть у 144 товаров, все видимые.
- Брал строку модели из паспорта WERA: «7440 x 0,3-1,2 Nm», «Click-Torque C 3 … 1/2" x 40-200 Nm».
- **Отвёртки с уставкой** (7450–7463, 1460 / 1461) — это диапазон модели. Уставка записана в скобках: «7460 x 0,3 Nm x 0,3-1,2 Nm» → 0,3–1,2, уставка 0,3. Где в паспорте «…001» диапазона модели нет (1460 / 1461 ESD, 7465 / 7466 Imperial), он взят из паспорта той же модели «…010».
- **Индикаторы** — одно значение: «300 TX … TX 15 x 3 нм» → 3 Н·м.
- **Imperial** — как у WERA, в in·lb.
- **Наборы** — диапазоны динамометров из их состава. Например, 7440/41/42: 0,3–1,2 + 1,2–3,0 + 3,0–6,0.
- **Набор для рекалибровки 05137003001** — в паспорте момента нет (раздел 6).

- **Несколько значений** — только у 5 наборов, где в составе 2–3 динамометра.
- **По разделам** Хорошоп показывает только значения своих товаров. Индикатори — 8, регульовані зі шкалою — 7, встановлений момент — 7, Click-Torque з тріскачкою — 7, Click-Torque для змінних інструментів — 7, наборы — 13, Halfmoon / HIOS — 4, Діелектричні — 3. Это укладывается в «10 + Показать еще».
- **Плюсы:**
  - ничего не придумано — значения как в названии модели WERA, по ним покупатель и ищет («7441 1,2–3,0»);
  - ни один товар не попадает в чужое значение;
  - в Halfmoon / HIOS и встановленому моменті впервые появится выбор — сейчас там у всех «до 1».
- **Минусы:**
  - в общем справочнике 36 значений; порядок задаётся посевом по возрастанию, как у размеров;
  - чтобы найти «любой инструмент на 3 Н·м», надо отметить несколько диапазонов: 1,2–3 / 1,7–3,5 / 2–6 / 2–12 …;
  - in·lb — отдельные значения, их стоит ставить после Н·м.

### Вариант (б): корзины, за границу которых товар не выходит

**Почему не фиксированные интервалы.** Корзины-интервалы, в которые каждый диапазон входит целиком, не получаются: диапазоны WERA перекрываются без разрывов от 0,02 до 1000 Н·м (0,1–0,34 / 0,3–1,0 / 0,9–1,5 / 1,2–3 / 2–6 / 2–12 / 2,5–25 / 10–50 …). Любая граница режет чей-то диапазон.

**Что работает.** Корзина по верхней границе: «до 0,4 / до 1,5 / до 4 / до 9 / до 25 / до 100 / до 400 / до 1000 Н·м». Товар получает одну корзину — наименьшую, в которую помещается его максимум. Это всегда правда: 0,3–1,2 → «до 1,5 Н·м».

**Сколько товаров в корзине:** до 0,4 — 15; до 1,5 — 35; до 4 — 30; до 9 — 21; до 25 — 17; до 100 — 14; до 400 — 13; до 1000 — 2. in·lb пересчитаны по 0,113 Н·м. Несколько корзин — только у 3 наборов.

**Минус.** Корзина говорит только про максимум. Кому нужно 3 Н·м, тот в «до 4» увидит и 0,4–2,0 (не дотянет). Ключи 2–6 и 2–12 окажутся в «до 9» и «до 25», а не рядом. То есть выбор по корзине опять неточный, просто в другую сторону.

### Рекомендация: вариант (а)

Точные диапазоны WERA: они не врут ни в одну сторону и совпадают с тем, как WERA и покупатель называют модель. Длинный список в разделах не появляется — максимум 13 значений, в наборах.

Запись — по твоему «ок»:
- новые значения в справочник «Діапазон моменту» посевом по возрастанию, in·lb в конце;
- 144 товара — бэкап → dryRun → запись → сверка выгрузкой;
- проверка всех затронутых разделов на витрине.

Старые 6 корзин после этого удалить — тоже по твоему решению.

## 3. «Ручки-тримачі для вставок Kraftform Kompakt VDE» (9 товаров)

**Сейчас на витрине:** Вид інструменту → Особливості викрутки → Діапазон моменту → Налаштування моменту → Особливості динамометра.

**Состав раздела:**
- 5 динамометрических ручек VDE (вид «Динамометрична викрутка») — 7440, 7441, 7444 VDE и 7508, 7516 VDE. Их основные разделы — «Діелектричні динамометричні регульовані викрутки» и «Safe-Torque Speed».
- 4 обычные ручки VDE (вид «Ручка-тримач»): 837 i RA 05057490001, 3817 05003991001, 827 T i 05057481001, 05003990001.

**Что теряется.** В трёх фильтрах момента обычные ручки пропадают — у них нет момента. «Особливості викрутки» находит одну ручку: «Нержавіюча сталь» у 3817.

**Предлагаю:** Хіти продажів → Ціна → Вид інструменту → Особливості викрутки.
- «Вид» делит раздел ровно 5 / 4: кто ищет динамометр, отмечает «Динамометрична викрутка».
- Момент для этих 5 выбирается в их основных разделах динамометрии, где ручки-тримачі не мешают.
- На карточке момент, налаштування и особливості динамометра остаются: это список «Характеристики для сторінки товару» группы, он от фильтров не зависит.
- «Особливості викрутки» сейчас находит 1 товар. Можно не ставить — по правилу «признак ≥ 2 товаров» из 1.3 он не проходит. Тогда список: Хіти → Ціна → Вид інструменту.

## 4. «Спеціальні вставки Kraftform Kompakt VDE» — перехідники 712 i VDE

**Раздел, 6 товаров:**
- 4 шафові вставки — у всех «Довжина робочого кінця» 89 мм. Профиль: внутрішній квадрат ×2, тригранник, подвійна борідка.
- 2 перехідники 712 i VDE: 05006642001 и 05073702001 (SB). Паспорт: «Насадка-переходник Kraftform Kompakt A VDE 712 i, изолированная, 1/4", 1/4" x 154 мм … от внешнего шестигранника 9 мм до внешнего квадрата 1/4"».

**Что правильнее: не ставить фильтр «Довжина робочого кінця» в этом разделе и 154 мм не записывать.**
1. **154 мм — общая длина перехідника.** Робочого кінця (жала под винт) у него нет: на конце квадрат 1/4″ под головку. «Довжина робочого кінця» у вставок — длина вставки, которой работают по винту. Записать 154 значит смешать две разные вещи в одном фильтре. Твоё правило 22.10 то же: «перехідник 712 i VDE — "Довжина робочого кінця" не пишется».
2. **Даже с 154 мм фильтр ничего не выберет внутри вставок** — у всех четырёх 89 мм. Он только отделит перехідники от вставок, а это уже делает «Вид інструменту».
3. **154 мм — новое значение справочника**, которое больше ни у кого не встречается.

**«Профіль» теряет те же 2 перехідники** — у переходника профиля винта нет. Раздел маленький, весь на одном экране.

**Предлагаю:** Хіти продажів → Ціна → Вид інструменту. Если для шафових вставок профиль важен, оставь «Профіль» — это (в): перехідники в нём пропадут, но находятся по «Вид».

**Попутно.** У перехідників вид сейчас «Приладдя». По твоему правилу 22.10 (вид одиночного товара — по паспорту, по главной функции) и по аналогии с перехідниками Zyklop это «Перехідник»: паспорт называет товар «Насадка-переходник». Это предложение, без записи. Тогда «Вид» в разделе: Змінна вставка 4 / Перехідник 2.
