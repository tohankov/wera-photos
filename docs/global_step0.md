## 4. «Что поменять в админке» — 5 правок

Полный текст — в начале `docs/admin_plan_filters.md`:

1. **«Новинки і лімітовані серії»** (раздел группы): Хіти → Ціна → **Вид інструменту**. Эту группу ты в «готово» не называл, на витрине сейчас только «Ціна».
2. **«Біти та бітотримачі → Підставки для біт»:** Хіти → Ціна → **Вид інструменту**.
   - Новое — следствие записи: в разделе 5 підставок и 2 футляры Bit-Safe («Приладдя»).
   - Второй вид — 2 из 7 (≥ 20 %), поэтому по правилу «Вид» ставится.
   - Если не нужен — скажи, сделаю исключением.
3. **Динамометрія — «Динамометричний ключ Safe-Torque з функцією відключення»:** Хіти → Ціна → **Привід**.
4. **Динамометрія — «Насадки для зварювання»:** Хіти → Ціна → **Привід**.
5. **Динамометрія — «Ручки-воротки X-Power для змінних насадок»:** Хіти → Ціна → **Привід**.

Пп. 3–5 — разделы из 2 товаров. Вчера по отменённому правилу им поставили «Хіти → Ціна». По общим правилам у двух товаров раздела разный «Привід», значит фильтр ставится.

## 5. Пример по п. 2 «не біти в разделах бит» (предложение, без записи)

Сейчас у TL64 и у ручки 1014 стоят все размеры, «Довжина 30 мм», «Тип біти: Стандартна» и профили раздела «Мікробіти 4 мм Micro». Их поставили 19.10 «по разделу» — это не свойства подставки и ручки.

| Товар | Источник | Реальное свойство | Предлагаю |
|---|---|---|---|
| Ручка 1014 05051278001 | паспорт: «Ручка-держатель для бит с внешним шестигранным хвостовиком 4 мм … Подходит для бит 4 мм» | Хвостовик бит, которые она принимает: «Шестигранник 4 мм (Micro)» | оставить «Хвостовик»; снять «Розмір», «Довжина», «Тип біти», «Профіль» |
| TL64 Підставка для мікробіт (не трогаю — только предложение) | описание на сайте: «підставка для … мікробіт з приводом 4 мм (для 6 шт)» | то же — «Шестигранник 4 мм (Micro)» | то же |

Тогда в «Мікробіти» по «Хвостовику» ручка и подставка находятся. При выборе размера или профиля они пропадают — как товар без свойства, по твоему принципу.

05049002001 (набор: ручка 1014 + 20 бит) — набор, его размеры и профили настоящие, по составу; не меняется.

Это пример для «ок» — вся логика пойдёт в группу «Біти».
