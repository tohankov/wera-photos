## 1. Хорошоп: увімкнути фід Google

1. **Маркетинг → Маркетплейси.** Зараз у розділі немає жодного фіда (через MCP видно 0 записів). Якщо «Google Feed for Merchant Center» у списку немає — функція доступна на тарифі Standard і вище; уточнити в підтримці Хорошопа.
2. Відкрити **Google Feed for Merchant Center** → увімкнути → зберегти.
3. **«Налаштування параметрів»** (кнопка біля фіда):
   - Наявність: «В наявності» → `in stock`. Інші статуси («Немає в наявності» → `out of stock`, «Під замовлення» → `out of stock`, не `preorder`: для `preorder` / `backorder` Google вимагає дату надходження на сторінці товару).
   - Стан товару: «Новий» → `new`.
   - «Мультимовність» — увімкнути (окремий XML для UA і RU).
4. **«Налаштувати категорії»** → «Синхронізувати категорії» (кнопку натискаєш ти; синхронізація незворотна; можна лише після того, як фід увімкнено). Напиши мені «синхронізовано» — я прочитаю екран категорій через MCP (`horoshop_admin_feed_categories_get`: дерево Google підтягнулося, скільки пар уже є). Записати пари «наш розділ → категорія Google» MCP не вміє, тому їх ставиш ти в адмінці за моєю покроковою таблицею (розділ верхнього рівня → ID Google; підрозділи з іншою категорією — окремо), а я після цього знову читаю екран і звіряю кожну пару з `inventory\gm_google_categories.xlsx`. Таблиця погоджена: мітчики — 1184 Taps & Dies; Г-подібні ключі — 1632 Wrenches (окремої категорії Hex Keys у таксономії Google немає).
5. **«Згенерувати фід»** → скопіювати посилання UA і RU (вигляд `https://tl-shop.com.ua/marketplace-integration/google-feed/<alias>?langId=…`). Посилання надіслати мені — я перевірю XML (кількість товарів, title, gtin, mpn, price, availability, description).
6. Далі Хорошоп оновлює фід щоночі сам.

## 2. Хорошоп: оформлення замовлення — «Кур'єром Нової пошти»

Сторінка «Оплата і доставка» обіцяє кур'єра Нової пошти, а в кошику цього способу немає (вимкнений). Хорошоп попереджає, що без адресної доставки Google може заблокувати фід.

1. **Налаштування → Доставка** (способи доставки) → «Кур'єром Нової пошти» → увімкнути.
2. Дозволені оплати для нього: «Оплата при отриманні» (накладений платіж) і «Безготівковий розрахунок» — як у «Новою поштою».
3. Вартість: «за тарифами перевізника».
4. Перевірити оформлення замовлення на сайті: кур'єр з'являється, адреса вводиться.

Довідка: [Хорошоп — Оплата та доставка](https://help.horoshop.ua/uk/collections/2154169-оплата-та-доставка)

## 4. Merchant Center: підтвердження сайту

У Merchant Center: **Інформація про компанію → Сайт → Підтвердити**. Два способи ([Google](https://support.google.com/merchants/answer/176793), [Хорошоп](https://help.horoshop.ua/en/articles/6907855-domain-verification)):

**А. HTML-файл (рекомендую):**
1. У Google вибрати «Завантажити HTML-файл», скачати файл.
2. Хорошоп: **Налаштування → Утиліти → Файли для зовнішніх сервісів → + Додати**. Назва: «Google Merchant Center», файл — той, що скачали → Зберегти.
3. Перевірити, що файл відкривається: `https://tl-shop.com.ua/<ім'я файла>.html`.
4. У Google натиснути «Підтвердити», потім «Заявити права» (claim). Файл не видаляти.

**Б. Мета-тег:**
1. У Google вибрати «Тег HTML», скопіювати `<meta name="google-site-verification" …>`.
2. Хорошоп: **Налаштування → Загальні налаштування → Скрипти** → вставити тег у блок `<head>` → Зберегти.
3. У Google натиснути «Підтвердити».

## 5. Merchant Center: доставка

**Налаштування → Доставка та повернення → Доставка → + Додати службу доставки** ([Google](https://support.google.com/merchants/answer/6069284)):
- Країна: Україна, валюта UAH, назва: «Нова пошта».
- Час обробки замовлення: **0–1 робочий день** (на сайті: замовлення відправляються в день надходження), робочі дні пн–пт, час закриття прийому — твій (наприклад 15:00).
- Час у дорозі: **1–3 дні** (Нова пошта по Україні; уточни, якщо інакше).
- Самовивіз (Полтава) у звичайних налаштуваннях доставки Google не вказується.

**Вартість — ПРОПОЗИЦІЯ, не налаштовано (чекаю «ок»).**

Що зараз бачить покупець на сайті (перевірено 19.10.2026):
- Кошик (`horoshop_delivery_export` / оформлення замовлення): «Новою поштою» — ціна 0, «за тарифами перевізника» (`by_carrier`), тобто доставка НЕ додається до суми замовлення, покупець платить Новій пошті при отриманні. «Самовивіз м. Полтава» — 0 грн. «Кур’єром Нової пошти» (id 16) вимкнений, у кошику його немає.
- Сторінка «Оплата і доставка»: «Нова пошта» по Україні — від 90 грн, за тарифами перевізника; кур’єр — за тарифами перевізника.

Офіційні тарифи Нової пошти, посилки між відділеннями, з ПДВ ([novaposhta.ua/shipping-cost](https://novaposhta.ua/shipping-cost/), «дійсні з 10.09.2026»; посилки не змінювалися з 13.04.2026 — [новина НП](https://novaposhta.ua/news/novi-taryfy-nova-poshta/), [зміни з 10.09](https://novaposhta.ua/news/nova-poshta-onovliuie-taryfy-na-vantazhi-i-palety/)):

| Посилка | По Україні | По місту (Локал) |
|---|---|---|
| Мала, до 2 кг | 90 грн | 70 грн |
| Середня, до 10 кг | 135 грн | 115 грн |
| Велика, до 30 кг | 200 грн | 180 грн |
| Адресна доставка (кур’єр) | + 60 грн до тарифу | — |

- У тариф входить комісія за оголошену цінність до 500 грн; для дорожчих відправлень НП додає комісію — точну суму дивитися в калькуляторі НП перед налаштуванням.
- Накладений платіж (післяплата) — окрема комісія НП: 20 грн + 2% від суми ([НП, післяплата](https://novaposhta.ua/financial-services/money-transfer/to-sender/)). Це плата за спосіб оплати, а не за доставку, у ставку доставки Google її не включати; на сторінці «Оплата і доставка» варто її згадати.

Як задати в Merchant Center (Google не має розрахунку «за тарифами перевізника» для Нової пошти, потрібні конкретні суми, і вони не можуть бути нижчими, ніж реально заплатить покупець — [Google](https://support.google.com/merchants/answer/6069284)):
- **Рекомендую: таблиця за вагою** (90 / 135 / 200 грн за межами 2 / 10 / 30 кг) — точно відповідає тарифу НП. Умова: у фіді має бути вага товару (`shipping_weight`); перед вибором перевірю XML фіда, чи Хорошоп її передає і чи заповнена вага в товарах.
- Якщо ваги у фіді немає — **фіксована ставка 135 грн** (покриває все до 10 кг: майже всі товари). Важкі позиції (візок, великі валізи понад 10 кг) — окрема ставка 200 грн через мітку доставки, або не включати їх у фід, доки ставка не задана.
- Таблиця «за ціною замовлення» не підходить: вартість НП залежить від ваги, а не від суми.
- Щоб цифри не розходилися: на сторінці «Оплата і доставка» замість «від 90 грн» — ті самі 90 / 135 / 200 грн (+60 грн кур’єр), і в Merchant Center — ті самі суми.

**Налаштування → Доставка та повернення → Повернення → + Додати політику** ([Google](https://support.google.com/merchants/answer/10220642)):
- Країна: Україна.
- Повернення приймаються: так, **14 днів** з дня покупки.
- Способи: поштою (Новою поштою) і в магазині (Полтава).
- Вартість зворотної доставки: **оплачує покупець**.
- Комісія за поновлення запасів: немає.
- Повернення коштів: **у день звернення** (повна вартість товару).
- Стан товару: новий, без слідів використання, повна комплектація, ціла упаковка (як на сайті).
- Посилання на політику: https://tl-shop.com.ua/obmin-ta-povernennya/

Обидва факти вже є на сторінці «Обмін та повернення» і у вкладці «Повернення» на картці товару (19.10.2026). Спосіб повернення коштів: на картку або рахунок покупця.

## 7. Merchant Center: програма безкоштовних оголошень

**Розвиток (Growth) → Керування програмами → Безкоштовні товарні оголошення** → увімкнути ([Google](https://support.google.com/merchants/answer/9199328)). У новому інтерфейсі: **Маркетингові методи → Безкоштовні оголошення**.

## 8. Merchant Center: додати фід

**Товари → Додати товари → Додати з файлу → «Ввести посилання на файл»** ([розклад завантаження](https://support.google.com/merchants/answer/1219255)):
1. Фід UA: посилання з `?langId=` для української, мова — українська, країна — Україна.
2. Розклад: щодня, після нічної генерації Хорошопом (наприклад 07:00).
3. Фід RU: Google для України підтримує українську; російськомовний фід додавати лише якщо Merchant Center дозволить мову «російська» для країни Україна, інакше не додавати.
4. Через 1–3 дні: **Товари → Діагностика** — надіслати мені скриншот або список помилок.

Ризики відхилення ([availability](https://support.google.com/merchants/answer/6324448), [розбіжність мікророзмітки](https://support.google.com/merchants/answer/6098383)): ціна і наявність у фіді мають збігатися зі сторінкою товару і мікророзміткою. Зараз усі товари «В наявності», сторінки віддають `InStock` — збігається. Якщо товару фактично немає — змінити наявність у Хорошопі (або зняти галочку фіда), інакше це порушення.

## 9. Пізніше: онлайн-оплата в Хорошопі

Зараз увімкнені лише «Оплата при отриманні», «Готівкою», «Безготівковий розрахунок». У магазині вже є (вимкнені) модулі:
- **Для України:** LiqPay (ПриватБанк), WayForPay, monobank (Plata by mono), Portmone, RozetkaPay.
- **Оплата частинами:** «Оплата частинами» ПриватБанку, «Покупка частинами» monobank.
- Інші (для інших країн): PayPal, Stripe, PayU, Przelewy24, Paynet, maib, NETOPIA, Monri.

Порядок:
1. Укласти договір з платіжним сервісом (ТОВ «Техлайт»), отримати ключі (public / private key або token) у кабінеті сервісу.
2. Хорошоп: **Налаштування → Оплата** → потрібний модуль → увімкнути, вставити ключі, вибрати, з якими способами доставки він доступний.
3. Онлайн-оплата карткою потребує фіскального чека: ПРРО (Checkbox або Вчасно — інтеграції є в Хорошопі).
4. Тестовий платіж, потім оновити сторінку «Оплата і доставка» і вкладку «Оплата» на картці товару.

Довідка: [Хорошоп — Оплата та доставка (онлайн-оплати, модерація оплат)](https://help.horoshop.ua/uk/collections/2154169-оплата-та-доставка) · [Хорошоп — Зовнішні сервіси (Checkbox)](https://help.horoshop.ua/uk/collections/1006755-зовнішні-сервіси)
