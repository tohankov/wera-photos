## Вопросы

1. «Викрутка з набором біт»: ок на список 7.1 (однозначные)?

3. Одно значение «Підставка / тримач» для підставок и тримачів викруток и біт — или «Підставка / тримач для біт» только для біт, а для викруток своё?
4. «Приладдя для викруток» слить в «Приладдя» (одно название во всех группах)?
5. Инструмент 338 для пружинных клемм (05008101001, 05008102001, набор 05008100001) — «Викрутка» / «Набір викруток» или «Приладдя» / «Набір інструментів»?
6. Наборы с тріскачкою и другими инструментами (Kompakt SH / M1 / H1 / W, 9532) — «Набір інструментів», а не «Набір з тріскачкою»: ок?
7. Перенос / alt по п. 9: тримач Joker 05136413001 → «Гайкові ключі Joker»; індикатор 05005655001 — только в «Діелектричні»; шило 1427 и розширювач 1428 → alt «Спеціальні викрутки … Kraftform Micro»; велонаборы 05004182001, 05004184001 — убрать из «Викрутки → Приладдя»?
