## Источники пар (правила CLAUDE.md)

- **Одиночный инструмент** — его профиль и размер, сверка с первой строкой datasheet WERA (при расхождении верен datasheet).
- **Толщина шлица** — таблица серии WERA, затем datasheet, затем название.
- **Набор** — состав из datasheet (вложенные наборы раскрываются). Для каждого компонента берётся текст состава («PH 2 x 100 мм», «1 мм x 5.5 мм x 100 мм», «PZ/S # 1») или профиль и размер компонента в каталоге.
- **Наборы из `sets_fix.js`** — цитаты из datasheet.
- **Не инструмент** (ручка, держатель) — значения своего раздела в тех же профилях и размерах, что у него сейчас.
