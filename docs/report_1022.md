## Генераторы

Повторный прогон любой группы ничего не откатит. Проверено: объединение генераторов по «Виду» = сайт у всех 2582 товаров. Генераторы «Викрутки», Kompakt и «Діелектричні» совпадают с сайтом по всем своим характеристикам.

  - `finishKinds` — подключение к генераторам.

- **`vyd_sources.js`** — источники «Вида» по генераторам.
