## Генераторы — повторный прогон второй вид не вернёт

- **Zyklop** (`zyklop.js`): в разделах «Приладдя Zyklop …» товар получает «Перехідник», если паспорт WERA называет его «Переходник» или «Соединительная деталь». Иначе остаётся «Приладдя».
- **«Діелектричні»** (`vde.js`): товар со словом «динамометр» в названии — «Динамометрична викрутка» (раньше по разделу ручек получал «Ручка-тримач»). Решение владельца также записано в `KIND_OWNER` (`vyd_comp.js`).
- **Проверка:** вид по генераторам = сайт у всех 2582 товаров. Генераторы «Діелектричні», «Динамометричний інструмент», «Перехідники», «Викрутки», Kompakt совпадают с сайтом по всем своим характеристикам.
- **Zyklop**, две старые разницы, к записи отношения не имеют, не трогал (были и до правки):
  - 05049002001: генератор без `vyd_final` даёт «Набір викруток», а `vyd_final` и сайт — «Викрутка з набором біт». При импорте побеждает `vyd_final`.
  - 05004176001 Bicycle Set 8: длины головок записаны не Zyklop — генератор их не снимает.
