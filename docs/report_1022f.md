## 4. Пропуск «Патрон Rapidaptor» — по всему каталогу (БЕЗ записи, жду «ок»)

**Почему пропуск.** «Патрон Rapidaptor» — значение «Особливості викрутки». Его ставит генератор Kompakt (`kk.js`), но только по слову «Rapidaptor» в названии товара. Поэтому у наборов значения нет, хотя ручка с Rapidaptor у них в составе WERA. Так у Kompakt 400 05057470001 (в составе «416 R Поперечная ручка-держатель с патроном Rapidaptor»). Сейчас значение есть у 7 одиночных ручек (816 R, 813 R, 817 R, 3816 R, 826 T, 416 R, бітотримач 416 RA) и ни у одного набора.

**Как искал.** По каждому товару каталога проверил:
- у набора — состав WERA целиком, вместе с вложенными наборами: строка состава с «Rapidaptor», паспорт компонента с «Rapidaptor»;
- у одиночного — название и паспорт.

Фразы о совместимости («подходит к ручке с патроном Rapidaptor», «можно использовать с ручкой Rapidaptor») не считаются. Так отсеялись Bicycle Set 15 05004182001 и биты 9507 05073201001 / 05073202001.
