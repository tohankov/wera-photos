## Генераторы — по составу WERA, не по слову в названии

- **Правило — одно, `rapidaptor()` в `tools/cat/vyd_comp.js`.** Rapidaptor есть, если его называет:
  - название товара;
  - паспорт WERA;
  - у набора — строка состава WERA, паспорт компонента или вложенного набора.
- **Совместимость не считается.** Фраза перед словом «Rapidaptor» с «подходит», «можно использовать», «совместим» — это не патрон. Так отсеиваются Bicycle Set 15 и биты 9507.
- **Kompakt (`kk.js`):** раньше брал только слово в названии, теперь — это правило.
- **«Викрутки» (`vykrutky.js`):** раньше «Патрон Rapidaptor» не ставил вовсе. Теперь ставит по тому же правилу, в том числе ручкам и наборам.
- **Исключение — 05059293001** (Kompakt 60 с динамометрической викруткой). Он лежит в «Наборах з динамометричним інструментом» и в корне Kompakt, фильтра «Особливості викрутки» там нет. Это один из 109 «не трогать», поэтому вынесен в `RAP_SKIP`.
- **Проверка:** генераторы дают «Патрон Rapidaptor» ровно 57 товарам — 7, у которых значение было, и 50 записанных. Лишних 0, пропущенных 0.
- Генераторы Kompakt, «Викрутки», «Діелектричні» совпадают с сайтом по всем своим характеристикам.
