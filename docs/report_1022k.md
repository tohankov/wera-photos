## 2. Новые правила плана

1. **В разделах наборов — все «… у складі»:** PH, PZ, TX, SL, HEX, Квадрат, TX BO, PlusMinus.
   - Они идут в план даже без значений и даже с одинаковым у всех значением.
   - На витрине пустые Хорошоп прячет.
   - `plan_vs_site` и блок «Что поменять» лишние «… у складі» ошибкой не считают.
   - Проверка `night_docs` «заполнено у товаров раздела» их не проверяет.
2. **Раздел из 1 товара — своего списка нет. Из 2 товаров — свой список «Хіти продажів → Ціна».**
3. **«Одно значение у всех» сравнивает набор значений каждого товара**, а не число разных значений. «Довжина…» в мм — как раньше, остаётся. «… у складі» не касается.
