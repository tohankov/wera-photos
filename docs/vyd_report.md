# «Вид інструменту» против состава WERA — отчёт (21.10.2026)

## Причина ошибки 05049002001

«Вид інструменту» — общая характеристика: значения товару дают все группы, в разделах которых он стоит. У 05049002001 (Tool-Check Modular Micro 1: ручка Kraftform Micro 1014 + 20 мікробіт) их два:
- «Набір викруток» — от группы «Викрутки», раздел «Набори викруток для електронників, серія Kraftform Micro». Верно.
- «Набір з тріскачкою» — от группы Zyklop, через дополнительный раздел «Набори Zyklop Mini». В `tools/cat/zyklop.js` вид ставился по разделу: всё в разделах наборов с тріскачкою получало «Набір з тріскачкою», состав не проверялся. По тому же правилу ошибка была у адаптера 9549 и шарніра 9550, а ещё у 05049003001 (Г-ключі Tool-Check Modular Hex-Plus 1).

Похожие правила «по разделу / названию» без проверки состава нашлись ещё в трёх генераторах:
- `vykrutky.js` — всё в разделах наборов получало «Набір викруток»;
- `vde.js` — слово «індикатор напруги» в названии давало «Індикатор напруги» и наборам викруток с тестером;
- `g_kk.js` — ударной викрутке с набором біт давало одиночный вид «Ударно-поворотна викрутка» рядом с «Набір інструментів».

**Исправление.** Новый общий модуль `tools/cat/vyd_comp.js`: состав из даташита WERA (таблица «Содержимое», с вложенными наборами) и проверка, есть ли в составе то, что обещает значение. Генераторы теперь сверяются с ним:
- `zyklop.js`:
  - «Набір з тріскачкою» — только если в составе есть тріскачка; иначе вид по составу (головки → «Набір головок», Г-ключі → «Набір Г-подібних ключів», ручка + біти → «Набір викруток»);
  - «Тріскачка» — только если даташит называет тріскачку, иначе «Приладдя».
- `vykrutky.js` — «Набір викруток» только если в составе есть викрутка (или ручка + біти), иначе «Набір інструментів».
- `vde.js` — набор с тестером получает «Набір викруток», а не «Індикатор напруги».
- `g_kk.js` — ударная викрутка с набором біт получает только «Набір інструментів».

После правки генераторы меняют вид ровно у 10 исправленных товаров, у остальных ничего не меняется. Генератор = сайт по «Вид інструменту» во всех группах.

## Сколько проверено

- **Даташиты:** состав разобран у всех 3582 даташитов WERA (`tools/cat/ds_comp_all.js`), таблица «Содержимое» есть у 648.
- **Товары:** проверены все 2582 товара каталога, у которых заполнен «Вид інструменту» (2605 значений); у остальных 1009 этой характеристики нет. Скрипт — `tools/cat/vyd_audit.js`. Правила проверки:
  - «Набір …» — в составе (или в названии и тексте даташита) есть то, что обещает значение: тріскачка, викрутка, біти, головки, ключі, динамометрический инструмент и т. д.;
  - одиночный вид не может стоять на наборе (≥ 2 разных инструментов в составе; пояс + липучки, держатель + прокладка — не набор);
  - одиночный вид должен совпадать с названием товара в даташите: «Викрутка» — отвёртка, «Тріскачка» — трещотка и т. д.

Результат: **10 ошибок исправлено, 8 спорных, остальное совпадает с даташитами.**

**05049002001.** По составу — ручка-тримач и біти. Существующих значений, которые описывают это точно, два: «Набір викруток» и «Набір біт». Оставил «Набір викруток»:
- оно уже было у товара от его основного раздела «Набори викруток для електронників… Kraftform Micro»;
- в «Викрутках» ручка + біти записываются именно так («Викрутка з набором насадок»).

Если хочешь «Набір біт» — скажи.

**Последствие для фильтров.** Наборы с тестером (3) больше не попадают в «Індикатор напруги» фильтра «Діелектричні». Импакт-наборы (2) не попадают в «Ударно-поворотна викрутка». Так требует правило «набор не может быть одиночным видом».
